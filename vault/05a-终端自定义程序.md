## 接口与类型

设置键：

- `terminal:profiles`（新增）：JSON 数组 `TerminalProfile[]`；缺键或非法 JSON → 空数组；单项缺字段或 name/program 去空白后为空 → 跳过该项。
  ```ts
  interface TerminalProfile {
    id: string;      // UUID v4
    name: string;    // 显示名，也用作新建 tab 标题
    program: string; // 完整路径或 PATH 中的命令名（如 nu）
    args: string[];  // 每项一个独立参数，可为空数组
  }
  ```
- `terminal:shell`（取值扩展，类型 `ShellChoice`）：`default` | `powershell.exe` | `cmd.exe` | `profile:<id>`。旧值继续有效；其他字符串按可执行名原样传给后端（保持既有行为）。
- `terminal:shortcuts` 单项新增可选 `shell?: ShellChoice`；缺省表示跟随 `terminal:shell`。
- 三个键都以 `terminal:` 开头，已在配置导入导出的可迁移白名单内（`storage::is_portable_setting`），不改导入导出代码。

Rust 命令：

- `term_create(cwd?, shell?, args?: string[], command?) -> term_id`：新增 `args`。`shell` 缺省时忽略 `args`，走 `default_shell`；`shell` 去空白后为空 → 返回错误「程序路径为空」（在开 PTY 之前校验）；spawn 失败返回「启动「<shell>」失败：<原因>」，`shell` 不是绝对路径时追加「（若刚安装，可改填完整路径或重启 LuckyIsland）」（进程 PATH 只在应用启动时读取）。
- `term_detect_shells() -> DetectedShell[]`（新增，async + `spawn_blocking`）：`DetectedShell { name: string, program: string, args: string[] }`，只检测不写设置；前端用 `ipc-schemas.ts` 的 `isDetectedShellList` + `assertIpc` 校验返回值。

前端（`src/lib/terminal-profiles.ts`，新增）：

- `parseProfiles(raw: string | null | undefined): TerminalProfile[]`
- `splitArgs(text: string): string[]` / `formatArgs(args: string[]): string`：空白分隔，双引号包住含空白的参数，不做反斜杠转义。
- `resolveShell(choice: string | null | undefined, profiles): { shell: string | null; args: string[] | null; label: string; missing: boolean }`：`default`/空 → `shell: null`；`profile:<id>` 找不到 → 按 `default` 处理且 `missing: true`。
- `shellOptions(profiles): { value: string; label: string }[]`：内置三项在前，自定义程序按列表顺序在后。
- `mergeDetected(profiles, detected): { next: TerminalProfile[]; added: number }`：按 program（大小写不敏感、`/` 与 `\` 归一）+ args 去重。
- `term-store.addTab(opts?: { cwd?; command?; title?; shell?: string })`：`shell` 缺省读 `terminal:shell`；创建前读取最新 `terminal:profiles` 解析；失败抛错。
- `term-store.openTab(opts?)`：用户主动新建 tab（「+」、程序下拉、快捷命令）的入口，先清空错误行，失败原因写入错误行，不抛出。
- `term-store.getNotice() / setNotice(text | null)`：终端页错误行存于模块 store，compact↔expanded 重挂载后仍可见。

事件：无新增。

## 实现要点

- 后端 `CommandBuilder::new(program)` + `cmd.args(args)`；portable-pty 在 Windows 上按 PATH/PATHEXT 查找程序，因此命令名与完整路径都可用。
- 快捷命令写入 PTY 的结尾由 `\r\n` 改为 `\r`，与 xterm 回车发送的字节一致，避免 bash / nu 多执行一个空行。
- 检测放在 `src-tauri/src/terminal/detect.rs`：候选判定写成纯函数，文件存在判断、PATH 查找、WSL 发行版列表由调用方注入，便于单测。范围：
  - Nushell：PATH 中的 `nu.exe` → `%ProgramFiles%\nu\bin\nu.exe` → `%LOCALAPPDATA%\Programs\nu\bin\nu.exe`，无参数。
  - Git Bash：`%ProgramFiles%\Git\bin\bash.exe` → `%LOCALAPPDATA%\Programs\Git\bin\bash.exe`，参数 `--login -i`；不使用 `System32\bash.exe`（WSL 旧入口）。
  - WSL：读注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Lxss\*\DistributionName`，每个发行版一项 `wsl.exe -d <名>`，名称「WSL: <名>」；排除 `docker-desktop` 开头的发行版。不启动 `wsl.exe` 进程，避免拉起 WSL 服务或卡住。
  - windows crate 增加 `Win32_System_Registry` 特性（只加 feature，不加依赖，不改 Cargo.lock）。
- 启动失败：`openTab` 把后端错误写入终端页错误行；`ensureFirstTab`（打开终端页时自动建的首个 tab）在非 `default` 选择失败时回退 `default` 再建一次，错误行显示「<后端错误>，已改用默认 shell」；内置 default 本身失败不重试，只显示原因。
- 删除自定义程序：若它是 `terminal:shell` 当前值 → 改回 `default`；快捷命令里引用它的 `shell` 字段一并清除。运行时遇到不存在的 profile 也按 `default` 处理。
- 设置面板「默认 shell」下拉改为选中即写入，不再在同一事件里调用 `useDraftField` 的 `setDraft` + `commit`（见「顺带修复」）。
- 新建 tab 选择：`src/components/pages/terminal/NewTabMenu.tsx`，ChevronDown 按钮放在 tab 横向滚动区右侧（工具栏右组最前），因为「+」在滚动区内，下拉放进去会被裁掉；下拉列出 `shellOptions`，选中即用该程序建 tab，内置「自动」沿用「终端 N」标题，其余用程序名；样式复用 `Shortcuts.tsx` 的下拉，自定义程序随 `settings://changed` 即时同步。
- 快捷命令编辑（新增与行内编辑）加「运行程序」下拉：「跟随默认」+ `shellOptions`。
- 自定义程序列表拆到 `src/settings/TerminalProfilesSection.tsx`，交互沿用快捷命令列表（行内编辑、删除）；路径输入框旁「浏览…」用 `@tauri-apps/plugin-dialog` 的 `open` 选 `.exe`。
- 安全：程序路径只来自本机设置或经确认框的配置导入，只在用户新建 tab 或运行快捷命令时启动；不新增 capability，不引入 shell 插件。
- 禁止：不做终端配色/字体扩展，不做 tab 持久化，不改 `term_open_wt`。

## 测试要点

- Rust：detect 纯函数（PATH 命中优先于固定路径、回退路径、Git Bash 参数、多个 WSL 发行版与 docker-desktop 过滤、全部缺失返回空）；构建命令的辅助函数对空 program 报错、`args` 原样追加。
- 前端单测：`parseProfiles` 容错；`splitArgs` / `formatArgs` 往返（引号、连续空白、空串）；`resolveShell` 四类取值与缺失回退；`mergeDetected` 去重；`parseShortcuts` 保留合法 `shell`、丢弃非字符串 `shell`。
- 组件测试：选择默认 shell 后写入的是新值；删除被设为默认的 profile 后回退 `default` 并清除快捷命令引用；检测结果去重后追加。
- term-store：`addTab` 把解析后的 `shell` / `args` 传给 `term_create`；`ensureFirstTab` 失败回退。
- 真机：nushell / Git Bash / WSL 各开一个 tab 能输入输出；在 nu 里跑快捷命令只执行一次；路径失效时的错误提示与首个 tab 回退；配置导出再导入后自定义程序保留。
