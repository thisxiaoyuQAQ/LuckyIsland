## 本轮范围

### 实施

**A. 设置分类（纯前端，最低风险）**
把 `SettingsApp.tsx` 侧栏 13 个 tab 分组加小标题，tab id 与后端 allowlist 不变：

- 常规：`general` 总体 · `appearance` 外观 · `hotkeys` 快捷键 · `pages` 页面管理
- 数据页：`time_widgets` 时间组件 · `time_appearance` 时间外观 · `weather` 天气 · `stock` 股票 · `terminal` 终端 · `notify` 通知
- 智能：`ai` AI · `voice` 语音
- 底部独立：`about` 关于

**B. 贴顶停靠 + 新 UI 外壳**
新增 KV `window:ui_mode` = `island`（老 UI，默认）| `classisland`（新 UI），与 `window:visual_style` 正交（前者换形态，后者换同形态下的样式配方）。

- Rust：顶部间隙随模式变化——`classisland` 时 gap=0（窗口顶边贴 `monitor.position.y`），否则维持 `TOP_GAP_PHYSICAL=16`。把 gap 作参数穿过 `monitor.rs` 全部定位路径（`top_center_position`/`clamp_offsets`/`move`/`recover`/`restore`/`window_offset_apply`），启动 `restore_island_monitor` 即按持久化模式定位。
- Rust：新增命令 `window_ui_mode_set(app, db, mode)`——校验值 → 写 KV → 重新定位灵动岛（复用 restore 路径）→ emit `settings://changed{key:"window:ui_mode"}`；返回落盘后的规范模式串。
- 前端：`App.tsx` 容器按模式切换——`classisland` 去掉 `pt-3`、外层卡片改 `rounded-b-2xl rounded-t-none`（贴顶、只下圆角）；否则维持 `pt-3 + rounded-2xl`。
- 前端：新增 `src/lib/ui-mode.ts` 模块级 store（仿 `visual-style.ts`）；`useIslandSettings` 初始读取 + 订阅 `settings://changed`；`AppearancePanel` 加「界面模式」下拉（老/新 UI）。

**C. 新 UI 紧凑组件条**
`classisland` 模式的紧凑态（非展开、非胶囊）在 `IslandTopBar` 左区渲染并排组件条：`时间 · 日期 · 天气 · N 项待办`。复用各页 `compact` 自包含渲染（`ClockBlock`/`WeatherPage`/`TodoPage`），组件间加分隔点。展开态仍复用现有页面与页签，右侧操作按钮区保持不变。

### 明确不做（本轮）

- 不改窗口几何常量（`720×80`/`240×80`/`720×400` 不动），只改定位 gap 与外壳圆角/内边距。
- 不做组件条的可配置化（选哪些组件、顺序、轮播）——固定 `时间·日期·天气·待办`，配置化归后续。
- 不实现插件运行时/市场，不动 `ai/*`、`voice/*`（延续 [[luckyisland-plugin-market-roadmap]]）。
- `classisland` 与 `floating_ball`/`hover_expand`/`click_through` 保持正交，不新增互斥逻辑；组合行为以基线策略为准。

## 已冻结产品决策

- `window:ui_mode` 值域 `island | classisland`；缺键、空值、非法值一律回退 `island`（保持老用户升级无感）。
- 贴顶＝窗口顶边对齐 `monitor.position.y`（gap 0）+ 前端去 `pt-3` + 卡片只下圆角；纵向偏移 `window:offset_y` 仍可叠加（默认 0 即贴死）。
- 切换模式即时重定位并即时换壳；两窗口（岛/设置）经 `settings://changed` 同步回显。
- `window:ui_mode` 命中 `is_portable_setting` 的 `window:` 前缀，随 07a 配置导出/导入（无需改白名单）。
- 设置分组只改侧栏视觉分区，不改 `SETTINGS_TABS`、`parseSettingsTab`、`open_settings` tab allowlist。

## 接口与类型（增量 diff）

```rust
// monitor.rs
pub const UI_MODE_KEY: &str = "window:ui_mode";
fn read_top_gap(db: &Db) -> i32;   // classisland → 0，否则 TOP_GAP_PHYSICAL
fn top_center_position(monitor, window_width, top_gap, offset_x, offset_y) -> MonitorPoint; // 新增 top_gap 参
fn clamp_offsets(monitor, w, h, top_gap, offset_x, offset_y) -> (i32, i32);                 // 新增 top_gap 参
#[tauri::command] pub fn window_ui_mode_set(app, db, mode: String) -> Result<String, String>;
```

```typescript
// settings.ts
KEYS.windowUiMode = "window:ui_mode";
export type UiMode = "island" | "classisland";
export function parseUiMode(v: string | null | undefined): UiMode; // 非法/缺失 → "island"
export function windowUiModeSet(mode: UiMode): Promise<UiMode>;      // invoke window_ui_mode_set
// ui-mode.ts：applyUiModeSetting / getUiMode / useUiMode（仿 visual-style.ts）
```
