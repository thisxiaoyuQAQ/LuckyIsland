## 本轮范围

### 实施

1. 设置「AI」页与「语音」页顶部各加「卸载」按钮，点击先弹确认框；确认后执行卸载，页面切为只显示说明与「重新安装」按钮。
2. 卸载语音：停止监听 → 删除 `<app_data_dir>/voice-models/` 整个目录 → 写 `modules:voice:installed=false` → AI 面板麦克风按钮隐藏。
3. 卸载问答：确认框提示语音会一并卸载；执行顺序为卸载语音（若已安装）→ 隐藏 AI 面板 → 注销 `toggle_ai` 全局热键 → 托盘菜单移除「AI 助手」→ 写 `modules:ai:installed=false`。
4. 重新安装问答：写 `true` → 重新注册 `toggle_ai` 热键 → 托盘恢复「AI 助手」。语音不自动重新安装。
5. 重新安装语音：问答未安装时按钮不可用并提示「请先重新安装问答」；可用时写 `true`，页面回到现有语音设置，模型按现有下载流程重新下载。
6. 「快捷键」页 `toggle_ai` 一行在问答卸载后显示为已停用（不可录制），重新安装后恢复。
7. 启动时读取两个键：语音已卸载时不恢复监听；问答已卸载时不注册 `toggle_ai`、托盘不建「AI 助手」项。

### 明确不做（本轮）

- 不实现插件运行时、插件宿主、包管理、签名市场或第三方插件加载。
- 不从安装包移除 sherpa-onnx / onnxruntime DLL，不改 NSIS 打包配置。
- 不删除 `ai_conversations` 对话历史、`ai:*` 设置（含 Chat API Key）与 `wake:*` 设置。
- 不改变已安装状态下的任何 AI/语音行为。

## 已冻结产品决策

- 粒度：两个模块分开卸载；卸载问答连带卸载语音；语音可以单独卸载，问答继续可用（打字）。
- 数据：卸载只删除语音模型目录，其余设置与记录保留；重新安装后恢复原设置，语音模型需重新下载。
- 入口：只在设置「AI」「语音」页，不新增独立的模块管理页。
- 缺键视为已安装，老用户升级无感；`modules:*` 键是本机状态，不加入可迁移白名单，不随配置导出/导入。
- Rust 为唯一事实来源：卸载状态下相关命令一律拒绝，前端隐藏只是展示层。

## 接口与类型

新增设置键（`settings` KV，值为 `"true"` / `"false"`，缺键 = `true`）：

```text
modules:ai:installed
modules:voice:installed
```

新增命令与事件（Rust 与 TypeScript 保持一致）：

```rust
#[derive(Serialize)] #[serde(rename_all = "camelCase")]
pub struct ModuleStatus { pub ai: bool, pub voice: bool }

#[tauri::command] pub fn module_status(db: State<Db>) -> Result<ModuleStatus, String>;
/// module = "ai" | "voice"；非法值返回 Err。卸载 ai 时连带卸载 voice。
#[tauri::command] pub fn module_uninstall(app: AppHandle, db: State<Db>, module: String) -> Result<ModuleStatus, String>;
/// 安装 voice 时若 ai 未安装返回 Err("请先重新安装问答")。
#[tauri::command] pub fn module_install(app: AppHandle, db: State<Db>, module: String) -> Result<ModuleStatus, String>;
```

```text
modules://changed  payload: ModuleStatus   # 每次安装/卸载成功后广播，所有窗口据此刷新
```

既有命令的守卫（已卸载时返回 Err，错误文案「问答模块已卸载」/「语音模块已卸载」）：

```text
问答：open_ai_palette、ai_chat
语音：voice_start_listening、voice_download_model、voice_record_utterance
```

`hotkeys::apply` 在问答未安装时跳过 `toggle_ai` 的注册，但结果中返回其已存绑定（设置页按结果回显，空串会被误显示为未绑定）。`hotkeys_list` 每项新增停用标记：

```rust
pub struct HotkeyEntry { pub action: String, pub label: String, pub binding: String, pub default: String,
                         pub disabled: bool }   // 新增：所属模块已卸载，设置页不可录制
```

```ts
interface HotkeyEntry { action: string; label: string; binding: string; default: string; disabled: boolean }
```

托盘图标固定 id `main`（`TrayIconBuilder::with_id`），安装/卸载问答后按 id 重建菜单。

## 实现要点

- 卸载语音删除目录前先停止监听；模型下载进行中或按需录音进行中时拒绝卸载并返回错误。卸载期间占住 `VoiceState.downloading` 下载槽，避免与解压写入并发。
- 删除目录失败（文件占用等）时不写 `false`，返回错误，界面保持已安装。
- 卸载问答若隐藏 AI 面板、注销热键或改托盘任一步失败，回滚已执行的步骤并保持 `true`。
- 托盘菜单在启动与安装/卸载时按 `modules:ai:installed` 构建，「AI 助手」项位置保持在「设置...」之后。
- AI 面板（独立 WebView）监听 `modules://changed` 隐藏麦克风按钮；设置窗口两页与快捷键页同样监听该事件。

## 测试要点

- Rust：缺键视为已安装；`module_uninstall("ai")` 连带把 voice 置 false；问答未安装时 `module_install("voice")` 返回错误；非法 module 返回错误；`modules:` 前缀不属于可迁移设置。
- Rust：卸载状态下 `open_ai_palette` / `ai_chat` / `voice_start_listening` / `voice_download_model` / `voice_record_utterance` 返回对应错误。
- 前端：AI/语音页在卸载状态只渲染说明与「重新安装」；问答未安装时语音页「重新安装」禁用并显示提示；收到 `modules://changed` 后切换渲染；AI 面板语音卸载后不渲染麦克风按钮。
- 真机（用户）：卸载语音后 `voice-models` 目录消失、闲置内存不再含 KWS；卸载问答后 Alt+Space 无反应、托盘无「AI 助手」；重新安装后恢复，原对话历史与 API Key 仍在；重启应用后状态保持。

## 实现记录（2026-11-08）

- 与原产出清单的差异：卸载入口不改动 `AiHistoryPanel.tsx` / `VoicePanel.tsx` 本体，而是在 `SettingsApp` 用 `ModuleGate` 包住两页。卸载后原页面不挂载，它们的加载、订阅与自动启动监听都不会发生。
- 卸载问答的执行顺序：先卸载语音（唯一不可逆的一步：删除模型目录）；失败则直接返回，问答保持原状。语音成功后再处理问答入口；入口失败时回滚问答安装态，语音保持已卸载（模型已删除，无法回滚）。
- 安装态以 Rust 为准：生效语音态 = 问答已安装 且 语音键不为 `false`。前端读取失败时按已安装展示，实际动作仍由后端守卫裁决。AI 面板在读取完成前也按已安装显示麦克风；该窗口随启动预建，用户打开时状态早已读完。
- 三个命令都是 async：重建入口会调用 `hotkeys::apply`，在 sync 命令里会与主线程互等。
- 自动化：`pnpm typecheck` 通过；`pnpm test:frontend` 52 files / 506 tests 通过；`pnpm build:frontend` 通过；Rust 独立 target：fmt、clippy（`--all-targets -D warnings`）、`cargo check` 均 exit 0，`cargo test --lib` 175 passed / 1 ignored。clippy 与 cargo test 各出现过一次构建产物读取错误（E0463 / E0786），未改代码重跑即通过，判定为本机构建目录的偶发问题。
- 未做：真机 GUI 验证（只有用户能做）、实际删除用户的 `voice-models` 目录。

### 独立只读审查（2026-11-08）

属本模块的 3 条发现均已处理：
- 审查 #2（中低）：问答卸载期间被跳过的 `toggle_ai` 不占组合键，别的动作可抢走 Alt+Space，重装问答后 `toggle_ai` 静默注册失败。处理：抽出纯函数 `plan_registrations`，停用动作不注册但仍占住其组合键，别的动作再绑该键会在快捷键页报「与其它动作冲突」。新增 2 条单测。
- 审查 #4（低）：删除模型失败时唤醒监听已被停掉且不恢复。处理：卸载失败且卸载前在监听时尝试恢复监听；错误文案提示部分模型可能已删除、可重新下载。
- 审查 #5（低）：下载 / 按需录音的「先检查安装态、后占槽或置位」之间可被卸载插入。处理：下载占槽后、录音置位后各再校验一次 `ensure_voice`。录音与卸载之间仍有极小的交错窗口，结果是该次录音或卸载报错，不会写回模型。
- 复验：前端 53 files / 507 tests、Rust 179 passed / 1 ignored，fmt / clippy / check / build 通过。
