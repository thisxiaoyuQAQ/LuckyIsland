# LuckyIsland 模块 14 T4：边缘自动吸附贴边设计

> 日期：2026-08-17
> 状态：设计已批准，等待规格复核后进入实施计划
> 范围：模块 14 T4，同时补齐其依赖的最小 T3 Alt+左键拖动落点链路

## 1. 目标

让岛窗口可通过 Alt+左键拖动到当前显示器任意位置，并在窗口靠近显示器上、下、左、右边缘时自动吸附。贴左、右边后，岛的窗口几何和内容方向切换为竖向；拖离边缘后恢复横向自由定位。

本轮完成自动化实现、验证、独立审查和本地提交；不 push、不发布，完成后等待 Windows 真机验收。

## 2. 已确认产品规则

1. 当前界面模式使用独立键 `window:dock_edge:<mode>`，值域为 `top | bottom | left | right`，缺键、空值或非法值回退 `top`。
2. Alt+左键按下后调用 Tauri 原生拖动；普通左键和现有页面交互不受影响。
3. 吸附阈值为距显示器边缘 **48 物理像素**。
4. 松手时根据窗口外矩形到目标显示器四边的距离判断吸附：至少一边距离不超过 48px 时吸附，否则进入自由定位。
5. 四角同时命中多边时选择距离更近的一边；距离完全相等时优先保持当前停靠边；仍无法区分时按 `top → bottom → left → right` 选择。
6. 吸附后写入当前模式的 `dock_edge`，清除当前模式的 `offset_x/y`，并按该边基准重新定位。
7. 从边缘拖离超过 48px 后，`dock_edge` 恢复 `top`，但不跳回顶部：以 `top` 基准反算并保存当前落点对应的自由偏移。
8. 顶、底停靠为横向；左、右停靠为竖向。竖向时胶囊也旋转，逻辑尺寸由 `240×80` 变为 `80×240`。
9. T1 自定义长度在横向是窗口宽度，在竖向是窗口高度。compact 为 `80×length`；expanded 的窗口几何为 `400×length`，从所在边向屏幕内部展开。
10. `island` 模式沿边保留 16 物理像素间隙；`classisland` 模式沿边间隙为 0。垂直于停靠边的居中轴不额外加 gap。
11. 设置外观页提供停靠边手动选择；手动切换按新边归零偏移并立即重定位。
12. 新键继续命中既有 `window:` 可迁移白名单，随配置导入导出；不新增依赖或数据库迁移。

## 3. 推荐架构

采用“**Rust 后端作为窗口几何与物理定位真源，React 前端按方向切换内容布局**”的混合方案。

不采用纯 CSS 旋转整个页面：它会把文字、图标和交互坐标一并旋转，且原生窗口仍保持横向矩形，无法正确完成屏幕 clamp。也不把全部布局决策放入 Rust：Rust 只负责 OS 窗口矩形与位置，具体内容排列仍由 React 表达，符合当前项目边界。

### 3.1 共享停靠领域

Rust 定义 `DockEdge`，集中负责：

- 解析与规范化持久化值；
- 判断横向或竖向；
- 生成 `window:dock_edge:<mode>` 键；
- 向前端命令返回规范字符串。

TypeScript 定义对应 `DockEdge` 联合类型、解析函数、模式键和模块级 store。前端所有方向判断只读取该 store，不在组件内重复解析字符串。

### 3.2 后端几何

`window_policy` 的几何计算从 `geometry_for(state, length)` 扩展为带停靠方向的计算：

| 状态 | top / bottom | left / right |
|---|---:|---:|
| capsule | 240×80 | 80×240 |
| compact / hidden 兜底 | length×80 | 80×length |
| expanded | length×400 | 400×length |

窗口状态变化时的重锚不再固定为“水平中心”：

- top / bottom：尺寸变化保持水平中心，停靠边坐标保持不变；
- left / right：尺寸变化保持垂直中心，停靠边坐标保持不变；
- left 向右展开，固定窗口左边；right 向左展开，固定窗口右边；
- bottom 向上展开，固定窗口底边；top 向下展开，固定窗口顶边。

因此 compact、capsule、expanded 切换不会沿屏幕边缘漂移，也不会向屏幕外展开。

### 3.3 四边定位与 clamp

现有 `top_center_position` 泛化为按 `DockEdge` 计算基准位置：

- top：顶部 gap，水平居中；
- bottom：底部 gap，水平居中；
- left：左侧 gap，垂直居中；
- right：右侧 gap，垂直居中。

偏移始终解释为相对当前停靠基准的物理位移。clamp 以实际窗口物理宽高计算，保证完整窗口位于目标显示器可视矩形内；若窗口尺寸大于显示器某轴，则采用稳定的边缘约束而不触发 Rust `clamp` 的反向区间异常。

显示器切换、启动恢复、副屏断开与恢复、宽度变更、界面模式切换、配置导入后的重定位路径都统一读取当前 `DockEdge`，不保留仅支持顶部的旁路。

### 3.4 Alt 拖动与松手落点

前端拖动控制器负责手势生命周期：

1. 捕获左键且 `altKey=true` 的 `mousedown`；
2. 阻止该次手势触发现有点击展开和悬停阶段变化；
3. 调用 Tauri `startDragging()`；
4. 通过窗口移动事件识别 OS 拖动过程，在位置稳定后调用后端落点命令；不依赖原生拖动结束后可能无法可靠送达页面的单一 `mouseup`；
5. 卸载或新拖动开始时取消旧监听和计时器，使用 generation 防止晚到回调写入旧结果。

后端落点命令读取窗口外位置、当前窗口实际物理尺寸和目标显示器：

- 计算四边距离并按已确认规则选边；
- 命中阈值：保存新边、删除偏移、按边重定位；
- 未命中：保存 `top`，以当前位置反算 top 基准偏移，经 clamp 后落盘并重定位；
- 广播 `settings://changed`，让岛窗口与设置窗口同步方向和控件值。

边缘距离使用窗口外矩形，不使用鼠标坐标，避免 DPI、标题栏和指针抓取点差异导致吸附不稳定。

### 3.5 前端方向布局

前端不旋转整个 DOM，而是使用 `isVerticalDock` 切换布局语义：

- 外层容器尺寸与 Rust 几何一致；
- 顶部栏、页签/页点、紧凑组件条按竖向重新排列；
- left 内容朝右展开，right 内容朝左展开；
- 文字和图标保持正常阅读方向；
- 圆角和边框按贴边侧调整，贴屏边一侧去除对应圆角/边框；
- 现有页面功能、数据源和导航状态保持不变。

竖向 expanded 只有 400 逻辑像素的横向内容空间。页面内容沿用现有窄宽布局能力；若某页面仍有横向溢出，只做 T4 必需的容器约束，不顺手重构页面。

### 3.6 设置入口

`AppearancePanel` 增加“停靠边”选择，四个选项为顶部、底部、左侧、右侧。切换时：

- 调后端设置命令；
- 使用请求序号避免快速切换的晚响应覆盖新值；
- 成功后按后端规范值更新本地状态；
- 失败时恢复持久值并显示现有错误样式；
- 重置当前模式外观时把停靠边恢复为 `top`。

## 4. 错误处理与一致性

1. 写 `dock_edge` 或偏移失败时，命令返回错误，不广播成功事件。
2. KV 已成功写入但窗口重定位失败时，尽量恢复旧 KV；若 OS 窗口调用无法回滚，返回明确错误并由下次 restore 自愈，日志只记录位置和规范枚举，不记录敏感数据。
3. 非法持久值始终按 `top` 运行，不因坏配置阻止启动。
4. 拖动期间暂时抑制 hover；无论成功、失败、卸载或超时都恢复，不能留下永久禁用悬停的状态。
5. 所有物理距离和窗口位置计算都使用目标显示器的物理坐标；逻辑尺寸只在通过该显示器 scale factor 换算后参与计算。
6. 不修改 `window:ui_mode` 值域，不实现任务栏 T5，不引入新全局热键。

## 5. 测试设计

### 5.1 Rust 纯逻辑与命令边界

- `DockEdge` 四值解析、非法回退、按模式键命名；
- 四边基准位置，含正/负显示器坐标、两种 gap；
- 四边 clamp，含自定义长度、竖向宽高交换、高 DPI 物理尺寸；
- 四边状态几何及 capsule 旋转；
- 状态尺寸变化的边缘固定与中心重锚；
- 48px 内外边界；
- 四角最近边、同距保持当前边、稳定回退顺序；
- 吸附归零偏移与自由落点反算；
- 模式键彼此独立并命中 `window:` 迁移白名单。

### 5.2 TypeScript 与 React

- `DockEdge` 解析、键名、store 更新；
- Alt+左键才启动拖动，普通点击和无 Alt 不启动；
- 拖动控制器清理、generation 和 hover 抑制恢复；
- `settings://changed` 后按当前模式重读停靠边；
- 外观面板四边选择、快速请求乱序、失败回滚和重置；
- App 与顶部栏在竖向时使用方向布局，文本不使用整体旋转；
- 横向既有布局与 T1/T2 行为回归。

### 5.3 验证门禁

先运行 T4 定向前端/Rust 测试，再运行完整 `pnpm verify`，使用项目既有独立 `CARGO_TARGET_DIR` 和 sherpa 环境配置，避免争用用户的 `tauri dev` target。公共窗口定位和几何契约变更按自动定级应进入 L2 独立审查。

## 6. 真机验收清单

自动化和审查通过后仍只标记“待真机验收”，由用户验证：

1. Alt+左键可拖动，普通点击、滚轮、页面交互和 hover 不受影响；
2. 四边 48px 内吸附，48px 外保持自由位置；
3. 四角选择稳定，重复拖动不抖动；
4. 左右边显示竖条和竖向胶囊，文字/图标方向正常；
5. 四边 compact/capsule/expanded 均向屏内展开且边缘不漂移；
6. 自定义长度在左右边变为纵向长度；
7. 拖离边缘恢复自由定位且窗口不跳回顶部；
8. 重启、切换 island/classisland、切显示器、副屏断开恢复后位置正确；
9. 设置手动切边、重置、导入导出与双窗口同步正确；
10. T1 长度和 T2 双透明度无回归。
